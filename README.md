# Dead Stock Identification and Management

This Python script demonstrates how to identify and manage 'dead stock' in a small business inventory. It simulates an inventory system and flags items that have not been sold for a configurable period, offering basic management suggestions.

## Language

`python`

## How to Run

Save the code as a Python file (e.g., `dead_stock_manager.py`) and run it from your terminal using: `python dead_stock_manager.py`
